# WordPress Theme Trac Review Response

Use this format when preparing the final review comment.

Do not post anything automatically.

The human reviewer must verify the response first.

## Format

Hi @author,

Thank you for submitting your theme.

I reviewed the theme and found the following items.

### Required

For every required issue include:

1. Short issue title
2. File name
3. Line number when available
4. Relevant code when useful
5. Explanation
6. What needs to change
7. Official WordPress reference when applicable

### Recommended

List optional improvements separately.

Clearly state that these items are recommendations and do not block
approval.

### Notes

Add useful information that does not belong under Required or
Recommended.

### Next Step

Clearly explain what the theme author should do next.

## Writing Style

Be:

- Friendly
- Professional
- Specific
- Educational
- Concise

Do not:

- Accuse the author
- Use insulting language
- Present opinions as requirements
- Invent WordPress rules
- Claim uncertain findings are violations
